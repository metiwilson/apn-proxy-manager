# 🚀 Metiwilson APN Proxy Manager  
مدیریت حرفه‌ای و تمام‌اتوماتیک پروکسی ۳proxy، سازگار با تمام اپراتورها و مخصوص APN  
✨ *پایدار، امن، سریع — ساخته‌شده برای زیرساخت واقعی*

---

## 🔥 درباره پروژه
**Metiwilson APN Proxy Manager** یک ابزار کامل برای نصب، مدیریت، پیکربندی و کنترل پروکسی مبتنی بر **3proxy** است.  
این ابزار کاملاً سازگار با **APN موبایل** است و برای اپراتورها، شبکه‌های خصوصی، ارائه‌دهندگان پروکسی و سرورهای واقعی طراحی شده.

ویژگی اصلی این پروژه:  
✔ عدم ایجاد هرگونه تداخل یا آسیب به تنظیمات شبکه سرور  
✔ مدیریت آسان از طریق یک رابط خط فرمان حرفه‌ای  
✔ مناسب برای همه اپراتورها (همه SIM‑ها – Mobile‑Friendly/APN‑Friendly)

---

## ⚙️ امکانات
- 🚀 **نصب خودکار 3proxy** از سورس اصلی  
- 🔧 **تغییر سریع و ایمن** پورت، یوزر و پسورد  
- 🛡 **بدون تغییر خطرناک** در فایل‌های اصلی شبکه سیستم  
- 🔄 **آپدیت اتوماتیک اسکریپت** بدون حذف تنظیمات  
- 📡 **کاملاً سازگار با APN** (ایرانسل، همراه اول، رایتل و …)  
- ⚡ **راه‌اندازی سبک و سریع** با systemd  
- 🧰 لیست کامل ابزارها:  
  - مشاهده وضعیت سرویس  
  - نمایش لاگ‌های زنده  
  - حذف کامل فایل‌ها و سرویس  
  - بازتولید کانفیگ‌های پایدار  
- 📁 **ذخیره‌سازی تنظیمات** در `/etc/metiwilson`  
- 📜 **Log Rotation** برای جلوگیری از سنگین شدن سرور  
- 🧨 جلوگیری از خرابی سرور (Fail‑Safe Firewall / Zero‑Damage Mode)

## 📦 نصب (Installation)
برای نصب مستقیم و سریع، تنها کافی است:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/Metiwilson/proxy-panel/main/Metiwilson-Proxy.sh)
```

این دستور:  
✔ نصب می‌کند  
✔ سرویس می‌سازد  
✔ پیکربندی می‌کند  
✔ و آماده استفاده می‌شود

---

## 📱 استفاده برای APN موبایل
بعد از نصب:

```
Server: YOUR-IP or Domain
Port: 8080
User: your-username
Pass: your-password
```

نمونه تنظیم APN:

```
APN: internet
Proxy: your-domain.com
Port: 8080
```

قابل استفاده روی:  
✔ ایرانسل  
✔ همراه اول  
✔ رایتل  
✔ شاتل موبایل  
✔ تمام اپراتورهای جهانی
